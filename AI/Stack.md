Create the `Stack.md` file defining the technology stack for the marketing landing page.

The project is frontend-only.

Mandatory technology:

* React.js
* JavaScript
* Modern React functional components
* React Hooks where appropriate
* HTML5
* CSS

The document must define:

1. Frontend framework
2. Programming language
3. Styling approach
4. Routing approach
5. State management approach
6. Form handling approach
7. Validation approach
8. Animation approach
9. Image handling
10. Lazy loading strategy
11. Accessibility technologies
12. SEO technologies
13. Development tooling
14. Build tooling
15. Testing recommendations

Important constraints:

* Do not create a backend.
* Do not use Node.js as an application backend.
* Do not use Express.
* Do not use a database.
* Do not create authentication.
* Do not create API endpoints.

Use existing project dependencies if they are already defined.

Do not introduce unnecessary dependencies.

If a library is optional, explain why it may be used.

Prefer lightweight solutions.

The stack should support a long-term maintainable React application.

Clearly distinguish mandatory technologies from optional technologies.

Do not write implementation code.
